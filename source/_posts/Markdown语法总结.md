# 3.超链接

Markdown支持两种形式的链接语法：行内式和参考式两种形式，一般选择使用行内式更多一些。

## 3.1 行内式

**语法说明：**
[]里写链接文字，()写链接地址，()中的""中的文字可以为链接指定title属性，这个可加可不加。title属性的含义是可以实现鼠标悬停在链接上出现指定的title文字。其格式为：`[链接文字](链接地址 "链接标题")`这样的形式。()里的**链接地址**和**链接标题**之间有一个空格。

**代码：**
```
欢迎访问[村上秋水的却其顿小屋](http://blog.163.com/snowball_wang/)
欢迎访问[村上秋水的却其顿小屋](http://blog.163.com/snowball_wang/ "村上秋水的却其顿小屋")
```

**显示效果：**
欢迎访问[村上秋水的却其顿小屋](http://blog.163.com/snowball_wang/)
欢迎访问[村上秋水的却其顿小屋](http://blog.163.com/snowball_wang/ "村上秋水的却其顿小屋")

## 3.2 参考式

参考式链接多用于学术论文，便于对链接进行统一处理。

**语法说明：**

参考式链接分为两部分，文字的写法`[链接文字][链接标记]`，在文本的任意位置添加`[链接标记]: 链接地址 “链接标题” `，**链接地址**与**链接标题**之间有一个空格。

也可以将链接文字作为链接标记：`[链接文字][]`，然后在文本的任意位置添加`[链接文字]: 链接地址 “链接标题”`

**代码：**
```
推荐几个不错的网站[Baidu][1],[USTC][2]以及[村上秋水的却其顿小屋][3]。[村上秋水的却其顿小屋][3]是值得你关注的[博客][]。

[1]: http://www.baidu.com "百度"
[2]: http://www.ustc.edu.cn "科大首页"
[3]: http://blog.163.com/snowball_wang/ "村上秋水的却其顿小屋"
[博客]: http://blog.163.com/snowball_wang/ "村上秋水的却其顿小屋"
```

## 3.3 自动链接

**语法说明：**
Markdown支持以比较简单的自动链接形式来处理网址和电子邮件信箱。使用`<>`就会被自动转换成链接。

**代码：**
```
<http://www.baidu.com>
<wjq1996@mail.ustc.edu.cn>
```

**显示效果：**
<http://www.baidu.com>
<wjq1996@mail.ustc.edu.cn>

# 5. 引用

**语法说明：**

引用需要在被引用的文本前加上`>`符号。

**代码：**

```
> 这是一段引用
> 引用内容1
> 引用内容2
```

**显示效果：**

> 这是一段引用
>
> 引用内容1
>
> 引用内容2

## 5.1 引用的多层嵌套

区块引用可以嵌套(例如：引用内的引用)，只要根据层次上不同数量的`>`。

**代码：**

```
> 如何才能熟练掌握Markdown语法？ ---初级阶段
> >看教程 ---进阶阶段
> > > 多写文章 ---高级阶段
```

**显示效果：**

> 如何才能熟练掌握Markdown语法？ ---初级阶段
> >看教程 ---进阶阶段
> >
> > > 多写文章 ---高级阶段


## 5.2 引用其它的要素

引用的区块内也可以使用其他的Markdown语法，包括标题、列表、代码区块等。

**代码：**

```
> 1. 这是第一行列表项。
> 2. 这是第二行列表项。
> 代码示例：
> `print "Typora is such an amazing Markdown editor!"`
```

**显示效果：**

> 1. 这是第一行列表项。
> 2. 这是第二行列表项。
>   代码示例：
>   `print "Typora is such an amazing Markdown editor!"`


# 6. 插入图片

图片的创建方式与超链接相似，而且和超链接一样也有两种写法，行内式和参考式写法。

语法中图片Alt的意思是如果图片因为某些原因不能显示，就用定义的图片的Alt文字来代替图片。图片Title则和链接中的Title一样，表示鼠标悬停在图片上时出现的文字。Alt和Title都不是必须的，可以省略，但建议写上。

## 6.1 行内式

**语法说明：**

`![图片Alt](图片地址 "图片Title")`

**代码：**

```
海豹
![海豹](/Markdown语法总结/seal.jpg "海豹")
```

**显示效果：**

海豹

![seal](/Markdown语法总结/seal.jpg "海豹")



## 6.2 参考式

**语法说明：**

在文档要插入图片的地方写`![图片Alt][标记]`
在文档的最后写上`[标记]:图片地址 "Title"`

**代码：**

```
海豹
![海豹][seal]
[seal]: Markdown语法总结/seal.jpg "海豹"
```

**显示效果：**

海豹

![海豹][seal]
[seal]: Markdown语法总结/seal.jpg "海豹"

# 8. 表格

**语法说明：**

1. 不论是哪种方式，第一行为表头，第二行分隔表头和主题部分，第三行开始每一行是一个表格行。
2. 列与列之间用管道符`|`隔开，原生方式的表格每一行的两边也要有管道符。
3. 第二行还可以为不同的列指定对其方式。默认为左对齐，在`-`后加上`:`就右对齐。

**代码：**

简单表格：

```
姓名|学科|成绩
-|-|-
小强|数学|150
小赛|语文|150
小呆|英语|59
```

原生表格：

```
|姓名|学科|成绩|
|-|-|-|
|小强|数学|150|
|小赛|语文|150|
|小呆|英语|59|
```

表格单元内容设置为右对齐：
```
姓名|学科|成绩
|-:|-:|-:|
|小强|数学|150|
|小赛|语文|150|
|小呆|英语|59|
```



**显示效果：**

简单表格：

| 小赛   | 语文   | 150  |
